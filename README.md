## 3. 沟通风格偏好

> AI 应如何与你对话，才能最省力。

- **语言**：简体中文
- **长度**：默认简洁直接，结论先行；复杂话题再展开
- **提问方式**：偏好简短直接的提问，快速获取结论式答案
- **反馈风格**：习惯"继续"驱动多步交付；迭代式要求文本压缩（1/2 → 1/3）

## 版本与同步

- 本仓库始终保留完整 Git 历史；每次编辑都应以独立 commit 提交并写清说明。
- **查看历史**：`git log --oneline`
- **回退到某次提交**：`git checkout <commit-hash> -- README.md`（仅回退单文件）或 `git revert <commit-hash>`（生成反向提交，安全可追溯）
- **本地同步远程**：`git pull` 拉取，`git push` 推送。
- 详细初始化与首次推送步骤见 [`issues.md`](./issues.md) 末尾的"本地同步脚本"说明，或仓库根目录的初始化脚本。
